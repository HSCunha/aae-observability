# Security Policy

## Supported versions

Until the 1.0.0 general-availability release, only the latest published
pre-release line receives security fixes.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately
to the maintainers with:

- the affected version;
- reproduction steps or a proof of concept;
- the expected and observed behavior;
- the potential impact;
- any proposed mitigation.

The maintainers will acknowledge receipt within five business days, triage the
report, coordinate remediation and disclosure, and credit reporters who wish to
be acknowledged.

## Secrets and telemetry

Never include credentials, access tokens, connection strings, prompts, model
responses, or personal data in a vulnerability report unless explicitly agreed
through a secure channel. Sensitive telemetry capture is disabled by default.
